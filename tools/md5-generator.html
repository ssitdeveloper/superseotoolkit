What is MD5?

MD5 (Message Digest Algorithm 5) is a widely used cryptographic hash function that produces a 128-bit hash value (32 hexadecimal characters). Uses include:

  • File integrity checking
  • Data checksums
  • Password hashing (deprecated for security)
  • Cache busting

⚠️ Security Warning

MD5 is cryptographically broken! It should NOT be used for further authenticating cryptographic purposes. For password storage, use bcrypt, Argon2, or scrypt instead.

Characteristics

  • Hash Output: 128-bit (16-byte) hash
  • Format: 32 hexadecimal characters
  • Speed: Very fast to compute
  • Security: Cryptographically broken ⚠️

Example

Input: Hello World

3e25960a79dbc69b674ce2606f5a75bc

Why MD5 is No Longer Secure

  • Collision attacks found (2004)
  • Hash collisions are computationally feasible
  • Deprecated by NIST (2011)
  • Should only be used for non-cryptographic checksums
  • Use SHA-256 or SHA-512 for security-critical applications

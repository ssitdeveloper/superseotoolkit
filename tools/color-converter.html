HEX (#RRGGBB)

Hexadecimal color code. 6 digits representing Red, Green, Blue values (00-FF).

Example: #FF5733

RGB (R, G, B)

Red, Green, Blue values from 0-255. Used in CSS and web colors.

Example: rgb(255, 87, 51)

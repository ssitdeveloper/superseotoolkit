What is a Slug?

A slug is a URL-friendly version of a string. It's typically used in the URL path of a web page or post.

Slug Best Practices

  • Use lowercase letters: Slugs should always be lowercase
  • Use hyphens for word separation: Use - instead of spaces or underscores
  • Keep it short: Shorter URLs are better for SEO
  • Be descriptive: Include main keywords when possible
  • Avoid special characters: Stick to letters, numbers, and hyphens
  • Remove stop words: Consider removing articles like 'the', 'a', 'an'
  • Use hyphens, not underscores: Google treats hyphens as word separators

What is SHA1?

SHA-1 (Secure Hash Algorithm 1) is a cryptographic hash function that produces a 160-bit (20-byte) hash value. Uses include:

  • Git commit hash verification
  • Digital signatures (deprecated)
  • File integrity checking
  • TLS/SSL certificates (deprecated)

SHA-1 is deprecated for cryptographic purposes! Collision attacks are practical and have been demonstrated. Use SHA-256 or SHA-512 for new implementations.

Characteristics
